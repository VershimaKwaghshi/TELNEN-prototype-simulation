# TELNEN-prototype-simulation

This is a standalone TELNEN prototype for GitHub Pages.

Upload index.html to a GitHub repository and enable GitHub Pages from the repository root.

The prototype contains:

• 10K to 100M population scale simulation
• Capital Building
• Social Bond adoption and concurrent usage
• 50 percent hard stop
• 100 day manager restitution interception
• TE buffer after the 100 day interception window
• 35 percent owner, 35 percent manager, 30 percent TE withdrawal economics
• 15 percent of the TE withdrawal allocation routed to the referrer and 15 percent retained by TE
• 12 USD broker rebate per standard lot
• Restitution stress testing
• 100 day recovery curve
• Full TELNEN scenario event sequence
